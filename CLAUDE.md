# Umwelt RP — инструкции для работы с репозиторием

- Перед любой работой прочитай `docs/РУКОВОДСТВО.md` и следуй разделу «Правила кода». Обновляй руководство в том же коммите, где меняешь механику, сборку или правило.
- Владелец проекта работает только с телефона (Android), без ПК. Общение и все тексты игры — на русском.
- Перед пушем: `godot --headless --path . -- --audit` (должно быть «0 ошибок»). Для сети — сценарий из раздела 5 руководства.
- Релиз собирает `.github/workflows/build.yml`; сервер на Hetzner обновляется сам. Вручную на сервер ничего не выкладывать.
